## Instructions
1. Write a clear, scannable report in markdown format.
2. Lead with severity and impact -- busy operators need key info first.
3. Keep it under 500 words.
4. Use tables for data where appropriate.
5. End with clear next steps.

## Response Format
Return ONLY the markdown report content, no wrapping JSON. Start with the alert header.

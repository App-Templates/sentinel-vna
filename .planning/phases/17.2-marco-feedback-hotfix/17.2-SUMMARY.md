### HOTFIX-01 (V3) — Tooltip discriminant

- **Marco:** "facendo mouseover sul grafico, mostra sempre la label baseline al posto di current revenue"
- **Root cause:** `RevenueTrendChart.tsx:65-68` `formatter={(value, name) => ... name === 'revenue' ? 'Current Revenue' : 'Baseline'}` — `name` is sourced from `<Line name="...">` display-label prop, NEVER from `dataKey`. Comparison was always false → both rows rendered "Baseline".
- **Fix:** switched discriminant to the 3rd formatter arg `item.dataKey`. `(value, _name, item) => [formatCurrency(...), (item as { dataKey?: string } | undefined)?.dataKey === 'revenue' ? 'Current Revenue' : 'Baseline']`. Decouples discriminant from human display label — future `<Line name>` rename does not regress.
- **Files modified:** `frontend/src/components/charts/RevenueTrendChart.tsx` (+12/-2)

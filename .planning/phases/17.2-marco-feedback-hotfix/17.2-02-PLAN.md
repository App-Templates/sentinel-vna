Fix V4 (Marco email 2026-05-19): the chart caption in AlertDetailPage > Tab 1 "Revenue Impact" reads "Revenue Trend (7 Weeks)" at `RevenueStatusSection.tsx:141`, but the data series rendered shows 7 calendar days (the `useAlertTrend` hook fetches `/api/alerts/{id}/trend` which is 7 daily points, not 7 weekly points). The label is wrong; the data is correct.

Decision rationale (per `17.2-CONTEXT.md` "Decisioni operatore"): two paths existed —
- **Path A (label fix):** change the literal string from "(7 Weeks)" to "(Last 7 Days)". Single-line edit. Closes V4 by aligning the caption to what the user already sees.
- **Path B (data fix):** alter the `useAlertTrend` hook + backend trend endpoint to return 7 weekly aggregates (7w rolling same-weekday). Requires backend changes, larger contract review, snapshot impact.

**Path A chosen** for Phase 17.2 (hotfix scope, ship-before-respond-to-Marco urgency). Path B can be a backlog item if a future operator decides the chart's analytical value would be greater as 7-week. Documented in commit body.

Purpose: A wrong caption erodes trust in the dashboard ("if the label says weeks but I see days, what else is wrong?"). Aligning the label is the cheapest possible truthfulness restoration.

Output: Single file modified (`frontend/src/components/alerts/RevenueStatusSection.tsx`); single atomic commit. Pure 1-line label change + intent comment.

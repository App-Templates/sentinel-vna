# Phase 17.2 Plan 04: B1 Alert Detail Tab Accessibility Summary

**One-liner:** Tabs 3/4/5 on AlertDetailPage always reachable + always render visible empty-state cards, eliminating Marco's "non più accessibili" defect by dropping AlertDetailPage:259's render-guard short-circuit and adding section-level early-return empty-state cards to ContributorsSection + GeoBreakdownSection.

## Diagnosis findings (Task 1)

Per [17.2-04-DIAGNOSIS.md](./17.2-04-DIAGNOSIS.md), per-tab root cause:

| Tab | Field | Root cause | Marco's observation | Fix |
|---|---|---|---|---|
| 3 (Top Contributors) | `contributors=[]` | **(d) UX defect** — section reached, but emits misleading "Concentration (Top 3): 0.0%" line alongside DataTable's "No data available" fallback | half-bait layout looks "broken" | Early-return empty-state card |
| 4 (Geo Breakdown) | `geo_breakdown=[]` | **(d) UX defect** — section reached, renders half-empty-table / half-empty-pie 2-col grid | half-empty layout looks "broken" | Early-return empty-state card |
| 5 (Environment Split) | `environment_split=null` | **(b) render-guard short-circuit** at AlertDetailPage:259 — `Object.keys(env_split).length > 0` was falsy, section never invoked, content area blank below the (clickable) tab strip | "tab not accessible" — defensible reading: 0 user value on click | Drop the parent guard; pass `?? ({} as ...)` so EnvironmentSplitSection's own lines 22-37 empty-state renders |

Marco hit the defect on every single alert because the legacy backfill corpus produced no populated payloads — explains why the report uses universal language ("non più accessibili", not "su alcuni alert").

### HOTFIX-06 (D1) — Filter-aware Network totals link

**Before** (`PublishersPage.tsx` line 269 pre-fix + bare `linkHref` constant): clicking "Network totals" always opened `/api/metrics/network-totals` with no query string — operator always landed on the endpoint's default Google 2026-03-23 row regardless of which year/month/sell_type/country/tier/environment filters were active on the page.

**After** (Task 2 commit `6c953c6`):

1. New helper in `TopNDisclaimer.tsx`:
```tsx
function composeNetworkTotalsHref(
  base: string,
  filters?: TopNDisclaimerFilters,
): string {
  if (!filters) return base
  const qs = new URLSearchParams()
  if (filters.year !== undefined && filters.year !== '') qs.set('year', String(filters.year))
  if (filters.month && filters.month !== 'all') qs.set('month', filters.month)
  if (filters.sell_type_proxy && filters.sell_type_proxy !== 'all') qs.set('sell_type', filters.sell_type_proxy)
  if (filters.geo_cluster && filters.geo_cluster !== 'all') qs.set('country', filters.geo_cluster)
  if (filters.publisher_tier && filters.publisher_tier !== 'all') qs.set('tier', filters.publisher_tier)
  if (filters.environment && filters.environment !== 'all') qs.set('environment', filters.environment)
  const q = qs.toString()
  return q ? `${base}?${q}` : base
}
```

2. New typed surface on `TopNDisclaimer`:
```tsx
export interface TopNDisclaimerFilters {
  year?: number | string
  month?: string
  sell_type_proxy?: string
  geo_cluster?: string
  publisher_tier?: string
  environment?: string
}

export interface TopNDisclaimerProps {
  n: number
  className?: string
  filters?: TopNDisclaimerFilters  // ← new
}
```

3. `PublishersPage` call site forwards active filters via explicit destructure:
```tsx
<TopNDisclaimer
  n={data.length}
  filters={{
    year: filters.year,
    month: filters.month,
    sell_type_proxy: filters.sell_type_proxy,
    geo_cluster: filters.geo_cluster,
    publisher_tier: filters.publisher_tier,
    environment: filters.environment,
  }}
/>
```

**Backend contract note:** `/api/metrics/network-totals` today accepts only `date` + `channel` (`backend/api/routes.py:981`). The frontend now forwards `year/month/sell_type/country/tier/environment` — currently ignored server-side per FastAPI default (un-recognized query params silently dropped). When Phase 18 extends the backend to honor these keys, this component requires **zero** changes. Marco's request was that the URL **reflect the current filter context**, NOT that the endpoint behavior change — this plan honors that exactly.

**Reactivity:** React re-renders on filter change → `composeNetworkTotalsHref` runs on every render → href captures click-time filter state, not stale state (T-17.2-03-05 mitigation built in by default).

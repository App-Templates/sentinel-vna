improvements committed to `wip/pre-10.2-rescue` as `7ea4a74` onto local `main`.

The WIP commit makes 3 separable but related changes:
1. `backend/api/publisher_routes.py`: bacino dedup. Current `get_top_publishers`
   sums `bacino` naively across all parquet rows for a publisher; the parquet
   join replicates `bacino` across (channel_group) for each (publisher, date,
   environment, geo_cluster) cell, so the naive sum overcounts by the
   `n_channels` factor per cell. The fix groups by the natural cell key,
   divides by `n_channels`, then aggregates per-publisher. Side effect:
   `avg_coverage` and `fill_rate` (both of which divide by total_bacino) get
   corrected for free.

2. `backend/api/routes.py` `revenue_status_24h`: replace single-point YoY
   (one same-weekday-last-year value) with 7-week rolling average of 7
   same-weekday same-ISO-day points around the target weekday. Adds a
   per-hour synthetic YoY curve (`hours` array) using the baseline-hourly
   distribution as proportion. Adds `weeks_averaged` integer to the response.

3. `backend/api/routes.py` `revenue_status_24h`: add `complete_dates` detection
   (`>= 20 hours` per date), default `target_date` to last complete day (not
   raw max), and surface `available_dates` (last 7 complete days as `[str, ...]`).

4. `backend/api/routes.py` `revenue_status_24h_by_date`: a sibling endpoint at
   `GET /metrics/revenue-status-24h/{date_path}` that delegates to
   `revenue_status_24h(request, date=date_path)`. Required by Plan 06 / Phase
   13 static-deploy export (Vercel JSON snapshot precomputes responses by
   path-routed URL — query strings don't survive `vercel build` static export).

Purpose: WIP-04 atomic commit per R-03. Closes the bacino quantitative gap
(Vito email 4a Mondadori bacino 366M PBI vs 133M Sentinel — note: this fix moves
the naive output FURTHER FROM PBI, but the WIP intent is "make it

remains a publisher_family aggregation gap deferred to Phase 13). Closes the YoY
single-point fragility (current main returns `null` when prev year same-weekday
has zero revenue — the 7w rolling avg is robust to single-point gaps).

  ```python
  # Bacino (ad_requests) is duplicated across channels in the parquet join.
  # First aggregate to unique (publisher, date, env, geo) to remove channel duplication,
  # then sum across all dates for each publisher.
  n_channels = df_year.groupby(["publisher_id", "date", "environment", "geo_cluster"])["channel_group"].nunique()
  bacino_per_cell = df_year.groupby(["publisher_id", "date", "environment", "geo_cluster"])["bacino"].sum()
  # Divide by channel count to undo the join duplication
  bacino_corrected = (bacino_per_cell / n_channels).groupby("publisher_id").sum()
  pub["total_bacino"] = pub["publisher_id"].map(bacino_corrected).fillna(0)

  # Coverage = Fill Rate (same metric with corrected bacino)
  pub["avg_coverage"] = (pub["total_impressions"] / pub["total_bacino"]).where(pub["total_bacino"] > 0, 0.0)
  pub["fill_rate"] = pub["avg_coverage"]  # identical after bacino correction
  ```

    Content:
    "Gli alert arrivano su Slack con livello di dettaglio calibrato sulla severity, evitando che gli operatori debbano controllare la dashboard proattivamente.

    **Routing per Severity:**

    | Severity | Routing | Dettaglio | Quando |
    |----------|---------|-----------|--------|
    | P0 | Immediato | Report completo (contributors, geo, env, azioni suggerite) | Subito dopo generazione alert |
    | P1 | Daily Digest | Dettaglio medio (revenue, triage, top 3 contributors) | Digest giornaliero ore 09:00 UTC |
    | P2 | Daily Digest | Compatto (una riga con link dashboard) | Digest giornaliero ore 09:00 UTC |
    | P2-WATCH | Daily Digest | Compatto (una riga con link dashboard) | Digest giornaliero ore 09:00 UTC |

    **Template Block Kit:**
    - **P0 Full:** Header rosso + revenue status + triage + top 5 contributors + geo breakdown + env breakdown + azioni suggerite + link alert detail
    - **P1 Medium:** Header arancione + revenue status + triage + top 3 contributors + link alert detail
    - **P2 Compact:** Header giallo + revenue delta + triage label + link alert detail

    **Configurazione:**
    Gli admin configurano il webhook Slack dalla pagina /admin:
    1. Crea un webhook Slack nel workspace Adkaora
    2. Inserisci webhook URL e channel name in Admin > Slack Configuration
    3. Testa la connessione con il pulsante "Test Connection"
    4. Salva la configurazione (salvata in alerting_rules.yaml)

    **Daily Digest:**
    - Job schedulato alle 09:00 UTC ogni giorno
    - Raccoglie tutti gli alert P1/P2/P2-WATCH generati nelle ultime 24h
    - Invia un singolo messaggio Slack con riepilogo
    - Se nessun alert nelle ultime 24h, il digest non viene inviato
    - Endpoint manuale: POST /api/notifications/digest/send (per test o invio on-demand)

    **Delivery Status:**
    Gli alert mostrano delivery_status nel database:
    - slack_sent: Notifica immediata inviata con successo
    - slack_queued: In coda per daily digest
    - pending: Non ancora processato
    - failed: Invio fallito (webhook non configurato o errore Slack)

    **Retry Logic:**
    Le notifiche immediate (P0) hanno retry automatico con exponential backoff (max 3 tentativi). Le notifiche digest non hanno retry (se il digest fallisce, gli alert restano in pending_notifications)."

    **alert_feedback table:**
    Columns: feedback_id (TEXT PK), alert_id (TEXT FK→alerts), user_id (TEXT NOT NULL), feedback_type (TEXT NOT NULL, CHECK IN REAL/FALSE_POSITIVE_MANUAL_INTERVENTION/FALSE_POSITIVE_SEASONALITY/FALSE_POSITIVE_TECHNICAL/FALSE_POSITIVE_PUBLISHER_CAMPAIGN/FALSE_POSITIVE_MARKET_NOISE), comment (TEXT), publisher_id (TEXT, auto-extracted from contributors), timestamp (DATETIME DEFAULT CURRENT_TIMESTAMP).
    Index: idx_feedback_publisher.
    Purpose: Stores operator feedback. Publisher_id auto-extracted from alert contributors for historical tracking.

    **alert_assignments table:**
    Columns: assignment_id (TEXT PK), alert_id (TEXT FK→alerts, UNIQUE), assigned_to (TEXT NOT NULL), assigned_by (TEXT NOT NULL), assigned_at (DATETIME DEFAULT CURRENT_TIMESTAMP).
    Purpose: One assignment per alert. Email validation (@adkaora.com) enforced at API/Pydantic level. INSERT OR REPLACE pattern handles reassignment.

    **manual_interventions table:**
    Columns: intervention_id (TEXT PK), timestamp (DATETIME NOT NULL), publisher_id (TEXT NOT NULL), intervention_type (TEXT NOT NULL, CHECK IN PRICING_RULE/FLOOR_CPM/DEMAND_PARTNER_CONFIG/AD_UNIT_SETUP/POLICY_CHANGE/OTHER), description (TEXT), value_before (TEXT), value_after (TEXT), user_id (TEXT NOT NULL), created_at (DATETIME DEFAULT CURRENT_TIMESTAMP).
    Indexes: idx_interventions_publisher, idx_interventions_timestamp.
    Purpose: Tracks manual operator interventions. Timestamp index used for baseline exclusion queries.

    **alert_intervention_links table:**
    Columns: link_id (TEXT PK), alert_id (TEXT FK→alerts), intervention_id (TEXT FK→manual_interventions), linked_at (DATETIME DEFAULT CURRENT_TIMESTAMP).
    Purpose: Many-to-many junction linking alerts to interventions. Tracks which alerts led to corrective actions.

    **pending_notifications table:**
    Columns: id (TEXT PK), alert_id (TEXT FK→alerts ON DELETE CASCADE), severity (TEXT NOT NULL), channel_group (TEXT), timestamp (DATETIME), created_at (DATETIME DEFAULT CURRENT_TIMESTAMP).
    Index: idx_pending_notifications_created_at.
    Purpose: Queue for P1/P2 alerts waiting for daily digest. P0 alerts skip this table (immediate send).

    **pipeline_runs table:**
    Columns: id (INTEGER PK), run_id (TEXT), timestamp (DATETIME), channel_group (TEXT), trigger_type (TEXT), mode (TEXT), status (TEXT), duration_sec (REAL), llm_used (BOOLEAN), llm_fallback (BOOLEAN), alert_id (TEXT), error_message (TEXT), created_at (DATETIME).
    Purpose: Records every pipeline execution for performance tracking and debugging.

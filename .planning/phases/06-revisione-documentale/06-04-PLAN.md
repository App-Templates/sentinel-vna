    Add five new tables to the schema documentation after the existing tables:

    **alert_feedback table:**
    ```
    CREATE TABLE alert_feedback (
      id TEXT PRIMARY KEY,
      alert_id TEXT NOT NULL REFERENCES alerts(id),
      publisher_id TEXT,
      category TEXT NOT NULL CHECK(category IN ('REAL', 'FALSE_POSITIVE_MANUAL_INTERVENTION', 'FALSE_POSITIVE_SEASONALITY', 'FALSE_POSITIVE_TECHNICAL', 'FALSE_POSITIVE_PUBLISHER_CAMPAIGN', 'FALSE_POSITIVE_MARKET_NOISE')),
      comment TEXT,
      created_by TEXT NOT NULL,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    CREATE INDEX idx_feedback_alert ON alert_feedback(alert_id);
    CREATE INDEX idx_feedback_publisher ON alert_feedback(publisher_id);
    ```
    Purpose: Stores operator feedback on alerts. Publisher_id auto-extracted from alert contributors for historical tracking.

    **alert_assignments table:**
    ```
    CREATE TABLE alert_assignments (
      alert_id TEXT PRIMARY KEY REFERENCES alerts(id),
      assigned_to TEXT NOT NULL CHECK(assigned_to LIKE '%@adkaora.com'),
      assigned_by TEXT NOT NULL,
      assigned_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    ```
    Purpose: One assignment per alert. Email validation enforces @adkaora.com domain. INSERT OR REPLACE pattern handles reassignment.

    **interventions table:**
    ```
    CREATE TABLE interventions (
      id TEXT PRIMARY KEY,
      publisher_id TEXT NOT NULL,
      intervention_type TEXT NOT NULL CHECK(intervention_type IN ('FLOOR_PRICE_CHANGE', 'MCM_CONFIG', 'TARGETING_CHANGE', 'AD_UNIT_CHANGE', 'BLOCK_LIST', 'OTHER')),
      timestamp DATETIME NOT NULL,
      value_before TEXT,
      value_after TEXT,
      reason TEXT,
      created_by TEXT NOT NULL,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    CREATE INDEX idx_interventions_publisher ON interventions(publisher_id);
    CREATE INDEX idx_interventions_timestamp ON interventions(timestamp);
    ```
    Purpose: Tracks manual operator interventions. Timestamp index used for baseline exclusion queries.

    **alert_interventions table:**
    ```
    CREATE TABLE alert_interventions (
      alert_id TEXT NOT NULL REFERENCES alerts(id),
      intervention_id TEXT NOT NULL REFERENCES interventions(id),
      linked_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      PRIMARY KEY (alert_id, intervention_id)
    );
    ```
    Purpose: Many-to-many junction table linking alerts to interventions. Enables tracking which alerts led to corrective actions.

    **pending_notifications table:**
    ```
    CREATE TABLE pending_notifications (
      id TEXT PRIMARY KEY,
      alert_id TEXT NOT NULL REFERENCES alerts(id),
      severity TEXT NOT NULL,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    CREATE INDEX idx_pending_created ON pending_notifications(created_at);
    ```
    Purpose: Queue for P1/P2/P2-WATCH alerts waiting for daily digest. P0 alerts skip this table (immediate send). Created_at index used by digest job to fetch last 24h.

    Update the total table count in the section intro from existing count to current count + 5.

    Modify the "api" section in TechnicalDocs (around lines 597-649):

    Add new endpoint groups after the existing endpoints:

    **Feedback Endpoints:**
    - POST /api/alerts/{alert_id}/feedback - Submit feedback with category (REAL or FALSE_POSITIVE_*) and optional comment. Auth required, rate limit 30/min.
    - GET /api/alerts/{alert_id}/feedbacks - List all feedbacks for an alert. Auth required, rate limit 60/min.
    - GET /api/publishers/{publisher_id}/feedback-history - Get historical feedback for publisher with alert context. Params: limit (default 50, max 200). Auth required, rate limit 60/min.

    **Assignment Endpoints:**
    - POST /api/alerts/{alert_id}/assignment - Assign alert to team member. Body: {assigned_to: email@adkaora.com}. Email validation enforced. Auth required, rate limit 30/min.
    - GET /api/alerts/{alert_id}/assignment - Get current assignment for alert. Returns 404 if not assigned. Auth required, rate limit 60/min.
    - DELETE /api/alerts/{alert_id}/assignment - Unassign alert. Auth required, rate limit 30/min.

    **Intervention Endpoints:**
    - POST /api/interventions - Create intervention. Body: {publisher_id, intervention_type, timestamp, value_before?, value_after?, reason, alert_id?}. If alert_id provided, creates link in alert_interventions. Auth required, rate limit 30/min.
    - GET /api/interventions - List all interventions with filters: publisher_id?, from_date?, to_date?, limit (default 100, max 500). Auth required, rate limit 60/min.
    - GET /api/interventions/{intervention_id} - Get single intervention with linked alerts. Auth required, rate limit 60/min.
    - GET /api/publishers/{publisher_id}/interventions - Get interventions for publisher. Params: limit (default 50, max 200). Auth required, rate limit 60/min.

    **Notification Endpoints:**
    - GET /api/notifications/config - Get current Slack configuration (webhook_url masked, channel visible). Auth required, rate limit 60/min.
    - PUT /api/notifications/config - Update Slack configuration. Body: {webhook_url, channel}. Saves to alerting_rules.yaml. Auth required, rate limit 10/min.
    - POST /api/notifications/test - Test Slack connection with current config. Sends test message. Auth required, rate limit 5/min.
    - POST /api/notifications/digest/send - Manually trigger daily digest (useful for testing). Processes all pending notifications from last 24h. Auth required, rate limit 5/min.

## Clock Control Mechanism

**Decision:** `datetime.utcnow() - timedelta(hours=N)` (relative-time seeding). Freezegun not installed and not needed. Tests assert the `7h > 6h` invariant relative to real clock at test-run time. The bug class was string-comparison misbehavior, not boundary-crossing logic specifically — the relative-time approach covers the full invariant.

If the payload produces T-format timestamps, the bug class demonstrated by Test 3 is still active on the `timestamp` column.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API response → chart data prop | `trendData`, `environmentSplit`, `safeGeoBreakdown` arrive from TanStack Query hooks fetching `/api/alerts/*`. Pre-Phase-15: a malformed payload (e.g., `null` field, NaN, type mismatch) causes a render throw that propagates to the global ErrorBoundary, which shows full-page "Something went wrong" + reload button. Post-Phase-15: the throw is caught at the chart-area boundary, fallback renders in the chart container, the rest of the alert detail page remains functional. |
| chart render → ChartErrorBoundary | A throw inside `RevenueTrendChart`, `EnvironmentBarChart`, or `GeoBreakdownPieChart` is captured by the boundary's `getDerivedStateFromError` + `componentDidCatch` (Plan 15-02 contract). |

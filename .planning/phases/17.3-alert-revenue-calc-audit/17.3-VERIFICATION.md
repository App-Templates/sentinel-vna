### AUDIT-03 (Numeric ±2% PBI match — DOWNGRADED)

**Status:** Structurally unmeetable in Phase 17.3 scope, documented for next phase.

**For Sample 1 (GOOGLE_ADEX 2026-03-22 01:00):**

| Source | Revenue (gross) | vs PBI €662.67 |
|---|---|---|
| Sentinel DB (pre-fix, synthetic) | €736.01 | +11.1% off |
| Parquet (post-fix, real, top-50 filter) | €521.44 | -21.3% off |
| PBI (Marco truth source) | €662.67 | — |

The top-50 publisher filter applied during ETL (`scripts/etl_csv_to_parquet.py`) caps the aggregated revenue. Closing this gap requires either:
- Re-aggregating parquet without the filter (large impact, all phases affected)
- Implementing alert-detail layer query against `/api/metrics/network-totals` style endpoint (Phase 11 D1 pattern extension — Phase 18 candidate)
- Marco-supplied PBI numbers stored as a sidecar table for alert-detail UI cross-reference

**For Sample 2 (HEADER_BIDDING_MAGNITE 2026-03-20 07:00):**

| Source | Revenue | Notes |
|---|---|---|
| Sentinel DB (pre-fix, synthetic) | €1185.04 | Synthetic formula |
| Parquet (post-fix) | n/a | 0 HBM rows in hourly parquet |
| PBI (Marco truth source) | €688.71 | HBM 07:00 |

Closing this gap requires expanding upstream `hour_kpi.csv` to include 8 channels (not just GOOGLE_ADEX). This is v1.4 territory (Athena query expansion or Marco-provided HBM hourly dump).

**Verdict:** AUDIT-03 numerical target was set on assumption that fix alone closes the gap. DIAGNOSIS revealed the gap is multi-layered (timezone bug + top-50 filter + missing HBM ingestion). The 1-line tz-fix addresses the bug layer; the other two require structural work. Phase 17.3 honors AUDIT-03 by **documenting the path to closure** and shipping the **first layer** of the fix.

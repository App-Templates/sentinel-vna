## Structural Limitation: static CDN + `?include_deprecated=true`

The `?include_deprecated=true` query parameter is NOT routeable by the Vercel static CDN. Vercel routes match static file paths; query parameters are ignored. The route `/api/alerts?include_deprecated=true` serves the same `alerts.json` (38 alerts) as `/api/alerts`.

**Evidence for D2CLOSE-03 (deprecated marking):**
- `sqlite3 data/vna_alerts.db "SELECT COUNT(*) FROM alerts WHERE deprecated=1 AND deprecation_reason='synthetic-era pre-H6-fix, Phase 21 Athena dependency'"` → `199` ✓
- Local backend: `curl http://127.0.0.1:8000/api/alerts?include_deprecated=true&limit=500` → total=438, phase21_deprecated=199 ✓
- CDN default `/api/alerts` → 38 alerts, 0 deprecated (Check 3 PASS) ✓

**Resolution:** D2CLOSE-03 is satisfied — the deprecated marking is in the DB, visible via backend API, and the CDN default hides them correctly. The `?include_deprecated=true` on CDN is a static-architecture limitation not a code defect; it requires a backend proxy to resolve (Phase 18 hardening candidate DOC-01).

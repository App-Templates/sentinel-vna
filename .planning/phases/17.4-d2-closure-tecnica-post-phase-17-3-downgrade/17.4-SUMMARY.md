**2. [Rule 1 - Bug] Live DB corrupted — restored from git HEAD (Plan 04)**
- **Found during:** Plan 04 post-Task-1 dry-run (schema missing deprecated column)
- **Issue:** `data/vna_alerts.db` in working tree was 1.4MB corrupted copy (schema 2-channel, no `deprecated` column). `git checkout HEAD -- data/vna_alerts.db` produced truncated file. Fix: `git cat-file -p HEAD:data/vna_alerts.db` extracted correct 3.3MB copy.
- **Fix:** DB restored from git HEAD object store. Post-restore: 438 rows, deprecated column present, dry-run OK.
- **Commit:** None (no git change needed — restored to HEAD state)

**3. [Rule 3 - Blocking] Build order: build FIRST, then export AFTER**
- **Found during:** Plan 05 Task 1 (Vite build wiped dist/api/ after first export run)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] staticmethod() wrapper on cls.loader in RED scaffold**

- **Found during:** Task 2 GREEN execution (running tests after implementing the loader)
- **Issue:** RED scaffold pattern `cls.loader = _load_ad_unit_mapping` followed by `self.loader()` in test methods triggers Python's bound-method semantics — `self` is passed as positional `arg0` → `TypeError: _load_ad_unit_mapping() takes 0 positional arguments but 1 was given`. The RED commit `bad1b30` had this bug latent (only `ImportError` fired during RED, hiding it).
- **Fix:** Wrapped `cls.loader = staticmethod(_load_ad_unit_mapping)` in `setUpClass`.
- **Files modified:** `scripts/test_ad_unit_mapping_loader.py` (1 line + 2-line comment).
- **Verification:** `python3 -m unittest scripts.test_ad_unit_mapping_loader -v` → `Ran 6 tests in 0.476s OK`.
- **Committed in:** `f95b1fa` (GREEN commit — atomic with loader implementation, since loader passes its tests only when scaffold is fixed).

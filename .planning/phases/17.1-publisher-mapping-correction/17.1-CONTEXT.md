# Phase 17.1 — Publisher Mapping Correction (Excel-based authoritative loader)

## Why this phase exists

**Phase 17 hardcoded `MONDADORI_FAMILY = {Mondadori, Mondadori_npa, Mediamond, Adgage_mondocore}` is WRONG.**

Marco audit response 2026-05-18 clarifies:
- `Mondadori` = `Mondadori` + `Mondadori_npa` ONLY (2 ad_unit)
- `Mediamond` is a SEPARATE publisher (its own 2 ad_unit: `Mediamond` + `Mediamond_npa`)
- `Mondocore` is a SEPARATE publisher (`Adgage_mondocore` single ad_unit)

This is part of a much larger mapping pattern: the file `ad_unit_1_mapping.xlsx` (Marco-maintained, daily refresh recommended) is the **authoritative truth source** for collapsing raw `ad_unit_name` into clean PBI-style `publisher` names.

## The mapping file

**Path:** `/Users/admintemp/Downloads/ad_unit_1_mapping.xlsx`

**Structure:** 432 rows × 9 columns, zero NULLs
- `ad_unit_id` (int) — GAM ad unit ID
- `ad_unit_name` (str) — raw name as appears in CSV (corresponds to Sentinel `publisher_id` field)
- `region`, `publisher_country`, `account_manager`, `technical_account_manager` (Vito Sena often here), `zone`, `company` — context columns
- `publisher` (str) — **authoritative PBI publisher name** (the column we map TO)

**259 unique `publisher` values** in the file.

   - `AdGage_GrupoGodo` → "Grupo Godó"

   - `OLD` (147 ad_units) — placeholder for deprecated/migrated entities

   - `Grupo Multimedios` = `AdGage_GrupoMultimedios` + `AdGage_Multimedios` (both AdGage_-prefixed, no `_npa`)
   - This proves that simple `_npa`-stripping is INSUFFICIENT; the Excel mapping is required for correctness.

### Critical anti-patterns / pitfalls

1. **Don't strip `_npa` suffix as a shortcut** — Grupo Multimedios proves the rule fails (`AdGage_GrupoMultimedios` + `AdGage_Multimedios`, no `_npa`). Use the Excel mapping.
2. **Don't aggregate Mediamond into Mondadori** — Phase 17 did this, Marco corrected: separate publisher.
3. **Don't keep `OLD` cluster in Top Publishers** — 147 legacy ad_units would skew the top-N ranking heavily.
4. **Don't apply mapping AFTER the groupby** — must be BEFORE, otherwise multiple `_npa` rows pollute the group keys.
5. **Drilldown endpoints must accept the clean name** — frontend will navigate to `/publishers/Vocento`, backend must reverse-lookup all `ad_unit_name` mapped to `Vocento`.

<objective>
Implementare il sistema di feedback operatore per gli alert: l'operatore può confermare un alert come reale o segnalarlo come falso positivo scegliendo tra categorie predefinite (MANUAL_INTERVENTION, SEASONALITY, TECHNICAL, PUBLISHER_CAMPAIGN, MARKET_NOISE), aggiungere commenti testuali, e il sistema mostra lo storico dei feedback precedenti sullo stesso publisher.

Purpose: Abilitare il ciclo di feedback operativo che permette al sistema di accumulare conoscenza su quali pattern sono reali vs rumore per publisher specifici.

Output: Database schema + API endpoints + operations per feedback con categorie, commenti, e storico publisher.
</objective>

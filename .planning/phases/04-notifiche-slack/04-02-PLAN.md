**backend/db/schema.sql:**
Add new table after `alert_intervention_links`:
```sql
CREATE TABLE IF NOT EXISTS pending_notifications (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    alert_id TEXT NOT NULL,
    severity TEXT NOT NULL,
    channel_group TEXT NOT NULL,
    timestamp TEXT NOT NULL,
    created_at TEXT NOT NULL,
    FOREIGN KEY (alert_id) REFERENCES alerts(alert_id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_pending_notifications_created_at ON pending_notifications(created_at);
```

This table accumulates P1/P2 alerts for the daily digest. Index on created_at enables efficient "all pending from last 24h" queries.

Refactor `notifier_agent()` function to route based on severity:

1. **Add helper function `_should_send_immediate(severity: str, config) -> bool`:**
   - Load `immediate_severities` from `config.slack_notifications.immediate_severities`
   - Return `severity in immediate_severities`
   - Default to `["P0"]` if config missing

2. **Add helper function `_save_to_pending_notifications(state: AlertState) -> bool`:**
   - Extract alert_id, severity, channel_group, timestamp from state.alert_payload
   - INSERT INTO pending_notifications (alert_id, severity, channel_group, timestamp, created_at)
   - created_at = datetime.now(timezone.utc).isoformat()
   - Return True on success, False on error (log error via logger.error)

3. **Update `notifier_agent()` main logic:**
   - After saving to DB (`_save_to_db(state)`), check severity
   - If `_should_send_immediate(severity, config)`:
     - Send Slack immediately via `_notification_executor.submit(_send_slack, state)`
     - Log: "Sending immediate notification for {severity} alert"
   - Else:
     - Call `_save_to_pending_notifications(state)`
     - Log: "Saved {severity} alert to pending notifications for daily digest"
     - Do NOT submit to _notification_executor
   - Email behavior unchanged (still controlled by config.notifications.email_enabled)

4. **Update delivery_status dict:**
   - Add `"slack_queued": bool` for digest alerts
   - Set `slack_sent: True` for immediate, `slack_queued: True` for digest

Preserve existing retry logic, thread pool executor, timeout handling. Only change is the conditional branching based on severity.
